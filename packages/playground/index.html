FratmScript: JavaScript in napoletano

FratmScript è JavaScript con le parole chiave in napoletano (chist è per const, facc per function, stamm a dì per console.log), compilato in JavaScript da un compilatore scritto in Rust. Questa pagina è un editor che gira nel browser.

Leggi la guida a FratmScript o fai il tour in lezioni (in English: guide, tour) oppure il codice su github.com/kkratterf/fratmscript.
